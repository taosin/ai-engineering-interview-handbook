# 我的学习与成长计划

这是供个人复制填写的空白模板。先做[起点自测](../roadmap/start.md)，再选一个岗位方向；记录真实结果，未完成项保持空白。

## 本轮目标

| 项目 | 我的选择 |
| --- | --- |
| 目标岗位 | AI 全栈 / Agent 工程师 / LLM 应用开发 / Agent Infra，先选一个 |
| 自测证据 | 代码、测试、日志或演示的地址；没有证据的能力待验证 |
| 当前起点 | 基础补课 / AI 应用起步 / 已有项目查漏 |
| 当前里程碑 | M___；进入条件是否满足？ |
| 沿用的项目 | 自有项目或主线的工单与知识助手 |
| 每周可用时间 | ___ 小时；不可用的日期或时段另记 |
| 本轮最小交付物 | 一件可以运行或检查的产物，不写“学完某框架” |
| 本轮停止条件 | 什么证据出现后，才进入下一里程碑？ |
| 已知障碍 | 缺少基础、环境、数据、时间还是验证办法？ |

## 本周安排

| 时段 | 本次具体动作 | 预计用时 | 产物或证据 | 实际结果 |
| --- | --- | --- | --- | --- |
| 待填 | 理解当前产物需要的一项机制 | 待填 | 一段说明或最小例子 | 待填 |
| 待填 | 实现一个可检查的变化 | 待填 | 提交、运行输出或测试 | 待填 |
| 待填 | 关闭资料，回答到期复习项 | 待填 | 原始回答、反例与改正 | 待填 |
| 待填 | 验证本周交付物并回顾 | 待填 | 通过/未通过的断言及下一步 | 待填 |

具体分钟数参考[时间投入方案](../roadmap/README.md#pace)。超时后缩小产物或拆成两周，不删去验证步骤来凑进度。

## 周末复盘

- 本周哪一条验收已经有可重复检查的证据？
- 哪个解释仍依赖资料，哪个功能仍依赖 AI 代写且自己说不清？
- 哪个失败来自知识缺口，哪个来自实现、环境或数据？
- 下周只优先解决哪一个障碍？回退到哪个里程碑？
- 哪些旧题或技能到了复习日期？是否需要减少新内容？

复习明细可用 [review-log.csv](review-log.csv) 记录。若要讲述真实项目结果，再使用[项目证据模板](project-evidence.md)。
