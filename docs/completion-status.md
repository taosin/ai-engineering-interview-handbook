## M4 不应被两份演示直接“通关”

- [M4-C1](../roadmap/milestones.md#m4-c1)：L01 留下同操作一次副作用、不同操作分别执行的本地证据。
- [M4-C2](../roadmap/milestones.md#m4-c2)：L03 留下主体来源、上下文过滤、直接工具拒绝和导出副作用的本地证据。确定性回答桩不代表已经测试真实模型抗注入能力。
- [M4-C3](../roadmap/milestones.md#m4-c3)：L01 检查预算与未知结果；完整应用原有 M1–M3 及权限回归仍需在学习者自己的贯穿项目中运行。

仓库 CI 通过说明这些模块的所列行为断言满足预期，不能替代尚未接入的完整产品，也不能认定读者已经独立掌握。下一步应把两个模块接入同一个应用、使用同一批验收样本，再登记实际结果。

## 后续完成标准

1. **L02 可运行化**：复现按文字误去重与迟到响应覆盖；证明按事件身份重放、任务隔离、重建和取消确认，在两客户端及乱序下仍成立。
2. **L04 可运行化**：由固定逐任务原始结果计算有效成功率、延迟和成本；缺失、超时与重复副作用不从分母消失。
3. **自检试评**：请不同基础学习者实际完成，记录耗时、提示、理解分歧和失败；两位试评者用相同判据比较分歧，修正后发布新规则版本，保留历史。
4. **题解与模拟面试**：从已关联 Q/G/L 中补少量可复核的示范回答、错误回答和追问，不凭数量批量制造“标准答案”。
5. **来源维护**：继续按原帖日期与正文定位补充；对小红书、脉脉等无法获得可靠原帖的部分继续标明缺口，不把转载或应聘公司名当发布平台。

本页是待办与验收依据，没有创建定时任务、提醒或自动采集。
